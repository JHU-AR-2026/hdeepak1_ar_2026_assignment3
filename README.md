# Introduction to Augmented Reality – Assignment 3

**Author:** Harihar Prasad

This repository contains my solutions for Assignment 3 of JHU’s Introduction to Augmented Reality course. It includes browser-based AR exercises, a Python script, and the required 3D model asset.

## Running the Code

For the browser-based questions, start a local web server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` and navigate to the appropriate question folder.

Run the Python solution with:

```bash
python3 Q3/q3e.py
```

Install any missing Python dependencies with `pip` as needed.
